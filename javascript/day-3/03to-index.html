TO-INDEX Method Learning

If we want to find the index in a string we use this method.

Things to keep in Mind

  • When type a single character it gives u the index.
  • When you write a whole word and its there, gives you the first character index.
  • if there are two same characters, index will be of the first letter/character.
  • if the character is not there it will return -1.
  • it is also Case-Sensitive so it will have output -1.
