# Simon Says Game 🎮

A browser-based Simon Says memory game built with HTML, CSS, and JavaScript.

The game generates a random color sequence that the player must remember and repeat. With each successful round, the sequence becomes longer and the difficulty increases.

## 🎯 Features

- Randomly generated color sequences
- Increasing difficulty with each level
- User input validation
- Level tracking
- Game over detection
- Restart functionality
- Visual feedback for button interactions

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🧠 JavaScript Concepts Practiced

- Arrays
- Functions
- Event listeners
- DOM manipulation
- Conditional statements
- Loops
- Random number generation
- User input handling
- Game state management

## 🎮 How to Play

1. Press any key to start the game.
2. Watch the color that flashes.
3. Click the buttons in the same order as the generated sequence.
4. Each successful round adds another color to the sequence.
5. Clicking the wrong button ends the game.
6. Press any key to restart.
