DOM Navigation

The process of moving through the hierarchical tree structure of an HTML document using JavaScript properties

The Node Tree Relationships

The DOM organizes elements using standard family terminology based on their position.

  • Root Node: The very top of the tree (document), which has no parent.
  • Parent: The direct container node located exactly one level above.
  • Child: Nodes directly nested inside another element.
  • Siblings: Nodes that share the exact same parent element.
